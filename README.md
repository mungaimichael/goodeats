    <h1>Good Eats - Discover Your Next Meal 🍽️</h1>
    <p>Good Eats is a mobile application built with React Native that allows users to discover and plan their meals. It provides a seamless experience for browsing recipes, saving favorites, and creating recipes Users can also view detailed recipe instructions.</p>
      <h2>Features 🚀</h2>
     <ul>
        <li><strong>User Authentication:</strong> Securely authenticate users with email/password authentication </li>
        <li><strong>Recipe Exploration:</strong> Browse through recipes generated by AI to find the perfect meal.</li>
        <li><strong>Recipe Details:</strong> Get detailed information about each recipe, including ingredients, instructions, and nutritional data.</li>
        <li><strong>Meal Planning:</strong> Create and manage meal plans by saving your favorite recipes.</li>
        <li><strong>Interactive Animations:</strong> Experience smooth and responsive animations throughout the app.</li>
       <li><strong>Sharing:</strong> Share liked recipes as a PDF to other applications </li>
    </ul>
  <h2>Technologies Used 🛠️</h2>
    <ul>
        <li><strong>React Native:</strong> A framework for building native apps using React.</li>
        <li><strong>Expo:</strong> A platform for making universal React apps that run on Android, iOS, and the web.</li>
        <li><strong>Redux:</strong> A predictable state container for managing application state.</li>
        <li><strong>Reanimated:</strong> A library for creating smooth animations in React Native.</li>
    </ul>
